## Intent-Based Navigation Paths

### "I am new to the repository and want to understand it"
1. Start at [`docs/index.md`](file:///home/sprime01/projects/gauntlet-game-studio/docs/index.md) (Layer 0 Orientation).
2. Read [`docs/mental-model.md`](file:///home/sprime01/projects/gauntlet-game-studio/docs/mental-model.md) to understand core conceptual distinctions.
3. Review [`docs/terminology.md`](file:///home/sprime01/projects/gauntlet-game-studio/docs/terminology.md) for domain definitions.
4. Follow [`docs/tutorials/first-game-project.md`](file:///home/sprime01/projects/gauntlet-game-studio/docs/tutorials/first-game-project.md) to build and run a game.

### "I need to understand the architecture and write code"
1. Read [`architecture.md`](file:///home/sprime01/projects/gauntlet-game-studio/architecture.md) for top-level system decomposition and invariants.
2. Read the relevant subsystem guide in [`docs/subsystems/`](file:///home/sprime01/projects/gauntlet-game-studio/docs/subsystems/).
3. Trace the relevant execution path in [`docs/workflows/`](file:///home/sprime01/projects/gauntlet-game-studio/docs/workflows/).
4. Consult [`source-map.md`](file:///home/sprime01/projects/gauntlet-game-studio/source-map.md) to navigate directly to the concrete classes, functions, and tests.

### "I want to add a capability or asset"
1. Read [`docs/how-to/add-new-capability.md`](file:///home/sprime01/projects/gauntlet-game-studio/docs/how-to/add-new-capability.md) or [`docs/how-to/register-and-verify-asset.md`](file:///home/sprime01/projects/gauntlet-game-studio/docs/how-to/register-and-verify-asset.md).
2. Check [`docs/reference/contracts-and-schemas.md`](file:///home/sprime01/projects/gauntlet-game-studio/docs/reference/contracts-and-schemas.md) for data contracts.
3. Validate changes with [`docs/reference/gates-and-verification.md`](file:///home/sprime01/projects/gauntlet-game-studio/docs/reference/gates-and-verification.md).

### "I am debugging a failure or regression"
1. If the runtime fails to boot: read [`docs/how-to/debug-subsystem-readiness.md`](file:///home/sprime01/projects/gauntlet-game-studio/docs/how-to/debug-subsystem-readiness.md).
2. If Gauntlet settlement fails or contradicts: read [`docs/explanation/tri-channel-verification.md`](file:///home/sprime01/projects/gauntlet-game-studio/docs/explanation/tri-channel-verification.md).
3. Inspect runtime state using the surface defined in [`docs/reference/observability-bridge.md`](file:///home/sprime01/projects/gauntlet-game-studio/docs/reference/observability-bridge.md).
